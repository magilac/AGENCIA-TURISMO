# Examen Práctico: Portal Web de Turismo Quevedo

## Información del Estudiante
* **Estudiante:** María Isabel Agila Carrillo
* **Destino Asignado:** Quevedo - Los Ríos, Ecuador
* **Asignatura:** Diseño de Sitios Web

## Descripción del Proyecto
Este sitio web promociona la oferta turística, cultural, agroturística y gastronómica del cantón Quevedo en la provincia de Los Ríos, destacando sus icónicos puentes, el Río Quevedo y la afamada Ruta del Cacao Fino de Aroma.

## Estructura del Sitio Web (5 Páginas HTML5)
1. `index.html`: Página principal con banner Hero, presentación y buscador.
2. `destinos.html`: Catálogo interactivo con 6 atractivos turísticos locales.
3. `servicios.html`: Muestra 4 paquetes y tours turísticos promocionales.
4. `nosotros.html`: Información sobre la historia, misión, visión y valores de la agencia.
5. `contacto.html`: Formulario de reservas implementado con validaciones en HTML5.

## Tecnologías Utilizadas
* HTML5 Semántico (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`)
* CSS3 Puro (CSS Grid, Flexbox, Box Model, Animaciones y Variables CSS)
* Media Queries (`@media`) para diseño totalmente responsive en móviles, tablets y escritorio.
* Git & GitHub
* Publicación en GitHub Pages
